# Contact

cubes is a small open-source project made by Karthik Subramanian. The fastest way to reach a human about it is GitHub, where every conversation stays public and searchable for the next person with the same question.

## Bugs and ideas

Open an issue at [github.com/KarthikSubramanian07/cubes/issues](https://github.com/KarthikSubramanian07/cubes/issues). For a bug, it helps to include the device and browser you were using, the mode you were playing (for example Duel or Stack), and what you expected to happen. Screenshots are very welcome. Ideas for new modes, rule tweaks and balance arguments are welcome too; the balance notes in the repository explain how the current numbers were chosen.

## Security

If you find a security problem, such as a way to see another player's hidden board in a fog game or to take someone else's seat in a room, please report it privately through GitHub's private vulnerability reporting: [report a vulnerability](https://github.com/KarthikSubramanian07/cubes/security/advisories/new). Please don't open a public issue for it.
